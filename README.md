## ✨ Features & Architecture

- 🎨 **Warm Luxury Aesthetic**: Custom gold/warm brown color palette designed for high-end interior design showcase.
- 📱 **Mobile-First Responsive Layout**: Optimized for desktop, tablet, and mobile displays with compact navbar and mobile menu.
- 🎥 **Auto-Sequenced Showcase Video Trailer Carousel**: Seamless transition between logo intro cards and 4K showcase video clips with mobile touch swipe gestures (`touchstart` / `touchend`).
- 🖼️ **Categorized Interior Galleries**: Interactive lightboxes and expand/collapse grid showcases for:
  - Modular Kitchens
  - Luxury Living Room TV Units
  - Custom Bedroom Wardrobes
  - False Ceilings & Lighting
- 📄 **Brochure Download & Inquiry Modal**: Direct PDF brochure downloads and custom consultation form.
- 💬 **Click-to-Chat Float Widgets**: WhatsApp & direct call floating action buttons.
- 🚀 **SEO & Social Sharing Ready**: Includes OpenGraph meta tags, `sitemap.xml`, and `robots.txt`.

## 🚀 How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/Prashant1817/gruhasparsha-website.git
   ```
2. Navigate into the project folder:
   ```bash
   cd gruhasparsha-website
   ```
3. Open `index.html` in any web browser or launch with VS Code **Live Server**.
